# Konte Docs

User documentation for the [Konte](https://themeforest.net/item/konte-minimal-modern-woocommerce-wordpress-theme/23162599) WordPress theme by UIX Themes, built with [Astro](https://astro.build/) + [Starlight](https://starlight.astro.build/).

Live site: `https://docs.uix.store/konte/`

## Setup

Requirements: **Node 22 LTS** and **pnpm**.

```bash
nvm use            # picks up Node 22 from .nvmrc
pnpm install
pnpm dev           # http://localhost:4321/konte/
```

## Useful scripts

| Script         | What it does                          |
| -------------- | ------------------------------------- |
| `pnpm dev`     | Start the local dev server            |
| `pnpm build`   | Build the production site to `./dist` |
| `pnpm preview` | Preview the built site                |
| `pnpm check`   | Run Astro type-checking               |
| `pnpm format`  | Format all files with Prettier        |
| `pnpm lint:md` | Lint Markdown with markdownlint       |

## Writing a page

Every page lives in `src/content/docs/<section>/`. The filename becomes the URL slug.

```yaml
---
title: Topbar
description: Enable, style, and add items to the Konte topbar.
sidebar:
  label: Topbar # optional, defaults to title
  order: 1 # position inside its section
---
```

- `description` is the meta description — keep it specific and under ~160 characters.
- The sidebar is autogenerated per section folder; sections and their order are set in `astro.config.mjs`.
- Add `sidebar: { hidden: true }` to publish a page without listing it in the sidebar.

### Images

Screenshots live in `src/assets/images/` and are optimized by Astro at build time. Reference them relatively:

```md
![Topbar menu](../../../assets/images/header--topbar-menu.png)
```

Append `#alignright` (or `#alignrightfull`, `#alignleft`) to float a small screenshot beside the text on desktop.

### Callouts

Use Starlight asides: `:::note`, `:::tip`, `:::caution`, `:::danger`.

### Links

Link to other pages with relative paths and a trailing slash, e.g. `[Header options](../../theme-options/header/#topbar)`.

## Quality gates

A husky pre-commit hook runs **Prettier** and **markdownlint** on staged files. To run them manually:

```bash
pnpm format:check
pnpm lint:md
```

## Deploying

Deploys build the site, `rsync` `./dist/` to the VPS, then purge the Cloudflare cache for `/konte/*`.

- **CI:** `.github/workflows/deploy.yml` — manual `workflow_dispatch` for now; the `push: [main]` trigger is commented out until the secrets are configured. Secrets: `VPS_SSH_HOST`, `VPS_SSH_USER`, `VPS_SSH_KEY`, `VPS_DEPLOY_PATH`, `VPS_SSH_PORT` (optional), `CLOUDFLARE_ZONE_ID`, `CLOUDFLARE_API_TOKEN`.
- **Local:** `./deploy.sh` — supports `--dry-run` and `--no-build`; set `SSH_TARGET` / `SSH_PORT` / `DEPLOY_PATH` via env or a gitignored `.env`.

## Project structure

```text
.
├── astro.config.mjs              # site, base path, sidebar
├── src/
│   ├── content.config.ts         # Starlight content collection schema
│   ├── content/docs/             # all docs pages (one folder per section)
│   ├── assets/images/            # screenshots
│   ├── plugins/                  # remark plugins (image alignment)
│   └── styles/custom.css         # style overrides
├── deploy.sh                     # manual deploy script
└── .github/workflows/deploy.yml  # CI deploy
```
