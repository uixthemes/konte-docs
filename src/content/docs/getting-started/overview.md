We would like to thank you for purchasing Konte! We are very pleased that you have chosen Konte for your website, you will not be disappointed! Before you get started, please be sure to always search our documentation. The search field is at the top of the sidebar allows you to quickly and easily search through our resources to find answers. We outline all kinds of good information and provide you with all the details you need to use Konte.

## Before you begin

Konte can only be used with WordPress, and we assume that you already have WordPress installed and ready to go. If you do not, please follow this link to go to [wordpress.org](https://wordpress.org/) to download and install the latest version of WordPress.

Please check the following pages before installing the theme:

- [WordPress Information](./wordpress-information/) - useful links and resources for WordPress.
- [Theme Requirements](./requirements/) - the minimum and recommended server configuration for Konte.

## How this documentation is organized

- **Getting Started** - theme requirements, included files, licenses, and support information.
- **Installation** - a step-by-step guide from downloading the theme to importing the demo content.
- **Theme Options** - all settings in the WordPress Customizer, from colors and typography to shop and blog layouts.
- **Elementor** and **WPBakery Page Builder** - build pages with the page builders supported by Konte.
- **Header**, **Pages**, **Shop**, **Portfolio**, and **Footer** - configure each part of your site.
- **Translation** - translate the theme or set up a multilingual store.
- **Customize Theme** - tweak texts, fonts, plugins, and the child theme.
- **Other** and **Updates** - extra features, the changelog, and how to update the theme.

## Quick start

If you are setting up Konte for the first time, follow these pages in order:

1. [Download the theme files from ThemeForest](../installation/download-theme/)
1. [Install the Konte theme](../installation/install-theme/)
1. [Install the required plugins](../installation/install-plugins/)
1. [Configure the image sizes](../installation/config-plugins/)
1. [Import the demo content](../installation/import-demo/)

After that, head to [Theme Options](../theme-options/customizer/) to adjust the look of your site, or to [Setup WooCommerce](../shop/setup-woocommerce/) to configure your shop.
