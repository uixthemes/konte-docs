# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

User documentation for the Konte WordPress theme, built with **Astro 6 + Starlight 0.39**. Hosted at `https://docs.uix.store/konte/`. Pure static documentation site that mirrors the setup of the `milano-docs` repository.

## Commands

```bash
pnpm install
pnpm dev           # http://localhost:4321/konte/
pnpm build         # production build → ./dist/
pnpm check         # Astro type-check
pnpm format:check  # Prettier
pnpm lint:md       # markdownlint
```

Pre-commit (husky + lint-staged) auto-formats and lints staged files. Do not bypass it.

## Architecture

- Pages are Markdown in `src/content/docs/<section>/`; `src/content/docs/index.mdx` is the splash homepage.
- `base: '/konte'` and `trailingSlash: 'always'` in `astro.config.mjs`. Never hardcode `/konte` in content; use relative links (`../../section/page/`).
- Sidebar: sections are listed in `astro.config.mjs` and autogenerated per folder; page order comes from `sidebar.order` frontmatter.
- Images: `src/assets/images/`, referenced as `../../../assets/images/<file>`. All images are centered in the content column (`src/styles/custom.css`).
- Callouts: `:::note`, `:::tip`, `:::caution`, `:::danger`.
- Package manager: **pnpm**.
